เปิดดู
เปิดลิงก์เว็บไซต์เพื่อดูวิดีโอได้ทันที หรือดาวน์โหลดไฟล์ MP4 ไปเปิดโดยตรง
หากดาวน์โหลดเป็น ZIP ให้แตกไฟล์ก่อน แล้วเปิด index.html
วิดีโอทั้งสองสัดส่วนใช้เนื้อหาและเวลาเดียวกัน

สถานะการช่วยเหลือบนหน้า HTML
กดเลือกตัวอย่างสถานะได้ 6 ขั้น:
รอรับเรื่อง → รับเรื่องแล้ว → เจ้าหน้าที่กำลังมา → ถึงจุดเกิดเหตุแล้ว → กำลังช่วยเหลือ → ช่วยเหลือเรียบร้อย
เริ่มที่รอรับเรื่อง ยังไม่มีทีมและเวลาที่จะมาถึง
เมื่อรับเรื่องแล้ว แสดง “ทีมช่วยเหลือตัวอย่าง”
เฉพาะขั้นเจ้าหน้าที่กำลังมา แสดง “ประมาณ 10–15 นาที (ตัวอย่าง)”
เมื่อมาถึง กำลังช่วยเหลือ หรือช่วยเหลือเรียบร้อย จะไม่แสดงเวลาที่คาดว่าจะมาถึง
สถานะเปลี่ยนเมื่อกดเลือกเท่านั้น ไม่มีการนับถอยหลังหรือส่งงานจริง
แผงนี้เป็นตัวอย่างที่กดดูได้บนหน้าเว็บแยกจากเครื่องเล่นวิดีโอ
กด Tab เพื่อเลือกปุ่ม แล้วกด Enter หรือ Space เพื่อดูสถานะได้

ภาพที่ใช้
บันทึกการใช้งานจริงจาก Flutter เวอร์ชันเว็บในขนาดหน้าจอมือถือ
แล้วจัดภาพในกรอบสมาร์ตโฟน ไม่ใช่ภาพจาก iOS Simulator
จุดแตะและเส้นลากเป็นภาพประกอบในขั้นตัดต่อ
ภาพและคลิปที่แนบเป็นไฟล์สถานการณ์สมมติ

ขอบเขตการสาธิต
เป็นโหมดทดลอง ยังไม่ส่งแจ้งเหตุจริง และไม่ได้โทรออกจริง
ฉากแนบสื่อใช้การเลือกไฟล์ที่เตรียมไว้ ไม่ใช่การสาธิตถ่ายกล้องบนมือถือ
วิดีโอนี้ไม่ใช่หลักฐานการทดสอบบนอุปกรณ์ iOS หรือ Android จริง
