# D/ID SOS — วิดีโอสอนใช้งาน

หน้าเว็บรวมวิดีโอภาษาไทย ความยาว 1 นาที 58 วินาที ไม่มีเสียง เปิดดูบนมือถือหรือคอมพิวเตอร์ได้ พร้อมดาวน์โหลดไฟล์ไปใช้ต่อ

- **แนวตั้ง 9:16** — 1080 × 1920 เหมาะกับมือถือ
- **แนวนอน 16:9** — 1920 × 1080 เหมาะกับงานนำเสนอ
- **มีข้อความสอน** — พร้อมเปิดให้ทีมดู
- **สำหรับตัดต่อ** — ไม่มีข้อความสอนภายนอกหน้าจอแอป ยังคงกรอบโทรศัพท์และป้ายสาธิต

## วิธีดู

เปิดหน้าเว็บไซต์ แล้วกดเล่นวิดีโอ เลือกปุ่ม “มีข้อความสอน” หรือ “สำหรับตัดต่อ” ได้ หากเล่นไม่ได้ ให้ดาวน์โหลด MP4 ไปเปิดโดยตรง

หากดาวน์โหลดทั้งชุด ให้เก็บไฟล์ทั้งหมดไว้ในโฟลเดอร์เดียวกัน แล้วเปิด `index.html` หลังแตกไฟล์ ZIP

## เนื้อหาที่สาธิต

เลื่อน SOS เพื่อสร้างคำขอจำลอง เลือกสถานที่และประเภทความช่วยเหลือ ระบุความเร่งด่วน แนบภาพหรือคลิป อัปเดตสถานการณ์ ตรวจข้อมูลก่อนบันทึก ดูสถานะตั้งแต่รับเรื่องจนเจ้าหน้าที่มาถึงและช่วยเหลือเรียบร้อย และเปิดรายชื่อเบอร์ขอความช่วยเหลือ

ภาพบันทึกจากเว็บแอปในขนาดมือถือและจัดในกรอบสมาร์ตโฟน ใช้สถานการณ์สมมติ ยังไม่ส่งแจ้งเหตุจริง และไม่ได้โทรออกจริง หน้าเว็บนี้เป็นหน้ารวมวิดีโอ ไม่ใช่ระบบรับแจ้งเหตุ และไม่ใช่ผลทดสอบบนอุปกรณ์ iOS หรือ Android จริง

## ลองดูสถานะการช่วยเหลือ

หน้า HTML มีตัวอย่างสถานะ 6 ขั้นให้กดเลือก:

รอรับเรื่อง → รับเรื่องแล้ว → เจ้าหน้าที่กำลังมา → ถึงจุดเกิดเหตุแล้ว → กำลังช่วยเหลือ → ช่วยเหลือเรียบร้อย

เริ่มต้นที่ “รอรับเรื่อง” โดยยังไม่มีทีมและเวลาที่จะมาถึง เมื่อเลือกรับเรื่องแล้วจะแสดง “ทีมช่วยเหลือตัวอย่าง” ขั้น “เจ้าหน้าที่กำลังมา” แสดง “ประมาณ 10–15 นาที (ตัวอย่าง)” และซ่อนเวลานี้เมื่อมาถึงหรือจบการช่วยเหลือ

สถานะเปลี่ยนเมื่อกดเลือกเท่านั้น ไม่มีการนับถอยหลัง การส่งงาน หรือการติดตามเจ้าหน้าที่จริง แผงนี้เป็นตัวอย่างที่กดดูได้บนหน้าเว็บแยกจากเครื่องเล่นวิดีโอ ใช้ปุ่ม Tab เพื่อเลือกและ Enter หรือ Space เพื่อเปิดสถานะได้
